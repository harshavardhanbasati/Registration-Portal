# Registration Portal

This frontend-only demo includes sign-up and sign-in forms. Demo accounts are
saved in the current browser's local storage; no backend or external API is
used. This is for local demonstration only, not production authentication.
Passwords are PBKDF2-hashed in the browser before being stored. Local browser
storage is still not a secure account system and should not be used for real
users or sensitive data.

## Run the project

From the project root, install the Node dependencies and start Vite:

```powershell
npm install
npm run dev
```
